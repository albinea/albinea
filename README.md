## Featured work

### [Mutual Fund Portfolio Agent](https://github.com/albinea/mutual-fund-portfolio-agent)
A full-stack portfolio analysis application for importing mutual-fund holdings, examining allocation and overlap, tracking NAV performance, and researching factsheets with citations. Its AI chat uses validated tools and source-backed data.

`React` `Django` `MySQL` `Qdrant` `Ollama` `Docker`

### [Production LLM Demo](https://github.com/albinea/production_llm_demo)
A Django LLM application focused on production practices: validated outputs, versioned prompts, fallback chains, correlation-ID logging, and regression coverage for prompts and schemas.

`Python` `Django` `Pydantic` `Testing` `LLM Engineering`

### [Scalable Async AI API System](https://github.com/albinea/scalable-api-async-ai-system)
An asynchronous API foundation for AI-powered applications, with task processing, agent integration, Docker support, and load testing.

`Python` `Async APIs` `Agents` `Docker` `Load Testing`

### [AI-Powered GitHub Project Explainer](https://github.com/albinea/AI-Powered-GitHub-Project-Explainer)
A web application that explains GitHub repositories with generative AI and interactive chat.

`Python` `Generative AI` `Web Development`
